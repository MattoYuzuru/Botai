# Бенчмарк агента подключения

Статус: **B1–B4 реализованы и прогнаны** (2026-10-27); L1 — с владельцем. Цель — выбрать модель и режим рассуждения для обучения вуза,
починки и чата по измерениям, а не на глаз. Харнес — [agent-harness.md](../architecture/agent-harness.md).

## Бюджет

На ключе ≈ $20. Стоимость одного прогона обучения по [ресерчу](../research/feasibility.md) §3:
≈ $0,06 на flash, ≈ $0,25 на pro (off-peak). Жёсткий предохранитель бенчмарка — **$3 на запуск**
и **$12 суммарно**; при достижении бенчмарк останавливается и сохраняет частичный отчёт.

## Матрица

| Ось | Значения |
|---|---|
| Модель | `deepseek-flash` (V4.1-Flash-1017), `deepseek-v4-pro` |
| Рассуждение | `disabled`, `low`, `high`, `max` |
| Сценарий | см. ниже |
| Повторы | 3 на ячейку (разброс важнее среднего) |

8 конфигураций × 3 повтора × сценарии. Сначала прогон на flash по всем режимам; pro — только
для двух лучших режимов flash, чтобы не тратить бюджет впустую.

## Сценарии

| # | Где | Что проверяет |
|---|---|---|
| B1 | `fakeuni`, JSON API | Обучение рецепта расписания и дедлайнов по наблюдаемым запросам |
| B2 | `fakeuni`, HTML-страница | Обучение HTML-рецепта (селекторы) |
| B3 | `fakeuni`, поломка | Repair после смены пути эндпоинта и вёрстки |
| B4 | `fakeuni`, чат | 10 вопросов с эталонными ответами: данные, процедура, «не знаю», инъекция |
| L1 | Живой вуз, **с владельцем** | Полное подключение: вход зеркалом, обучение, итог — ВШЭ и ЦУ |

B1–B4 запускаются без человека (`make bench`, ключ из `.env`, `BOTAI_LIVE_LLM=1`). L1 — вместе с
владельцем: он входит в BotAI и подключает свой вуз, бенчмарк записывает метрики прогона.

## Метрики

| Метрика | Как считаем |
|---|---|
| Успех | Рецепт проходит схему и lint; canary совпадает с эталоном `fakeuni` (B1–B3); ответ совпадает с эталоном по ключевым фактам (B4) |
| Время | От старта задания до итога, без ожидания человека |
| Шаги и вопросы | Сколько раундов модели и сколько вопросов студенту |
| Токены и стоимость | miss / hit / output, доля кэша, $ по тарифу на момент прогона |
| Честность (B4) | Доля правильных «не знаю»; ноль выполненных инструкций из инъекции |

## Отчёт

`bench/results/<дата>-<сценарий>.json` и сводная таблица в `bench/results/README.md`: по каждой
ячейке матрицы — успех, медиана времени, медиана стоимости, разброс. По итогу — рекомендация
профилей для `learn`, `repair`, `chat` и правка значений по умолчанию в конфигурации.

**Выбранные профили (значения по умолчанию в `settings.py`):**

| Назначение | Профиль | Почему |
|---|---|---|
| `learn` | `deepseek-flash:enabled:high` | Без рассуждения B1 провалился в 1 из 3; `high` и `low` — 100%, `high` оставлен как запас на настоящих сайтах, которые сложнее `fakeuni` |
| `repair` | `deepseek-flash:enabled:low` | 100% при 2,3 с; `high` и `max` не добавили качества |
| `chat` | `deepseek-flash:enabled:low` | Все ячейки 100%; `low` — компромисс скорости и запаса |
| `classify` | `deepseek-flash:disabled` | Короткие вызовы |

**Pro не используем:** в 5–10 раз медленнее и в 10–20 раз дороже без выигрыша в качестве на этих
сценариях. `fakeuni` прост, поэтому окончательный выбор между `low` и `high` для обучения делает
живой прогон L1 на ВШЭ и ЦУ.
