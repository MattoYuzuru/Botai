# W2 — Браузер и вход в вуз

Сначала прочитай [общие правила](README.md), затем [ADR-0001](../../adr/0001-login-form-mirroring.md),
[security.md](../../architecture/security.md) §0, §4 и [contracts/events.md](../../../contracts/events.md) §2.

## Владеешь

`backend/src/botai/browser/`, `backend/tests/browser/`, `backend/tests/fakeuni/login.py`.

## Цель

Сервер получает сессию вуза так, чтобы студенту было быстро и понятно: поля входа вуза
появляются как **нативные поля BotAI**, пароль сохраняется в Vault, повторный вход идёт сам.
Капчу и незнакомые шаги человек проходит на запасном экране, который не лагает.

## Срезы

1. **EgressProxy** (`browser/proxy.py`, запуск `python -m botai.browser.proxy`): asyncio
   CONNECT-прокси. Аутентификация запроса — `Proxy-Authorization` с одноразовым токеном
   подключения, по которому прокси знает allowlist хостов. Запрещены: хосты вне allowlist,
   IP-литералы, приватные и служебные диапазоны (10/8, 172.16/12, 192.168/16, 127/8, 169.254/16,
   ::1, fc00::/7, 100.64/10), порты кроме 443. DNS-пин: резолвим один раз, проверяем адрес,
   соединяемся с ним. Бюджет запросов на подключение. Для тестов — флаг, разрешающий
   `fakeuni.test` → 127.0.0.1. Тесты: редирект на чужой хост блокируется; `127.0.0.1` по IP —
   нет; `169.254.169.254` — нет.
2. **PlaywrightGateway** (`browser/gateway.py`) по протоколу `core.browser.BrowserGateway`:
   Chromium headless (Playwright 1.63.0), отдельный контекст на подключение, прокси = EgressProxy,
   профиль в памяти/tmpfs. `snapshot()` — URL, заголовок, видимый текст и HTML (обрезанные),
   формы с полями (`selector`, `type`, `autocomplete`, подпись), признак капчи (iframe
   reCAPTCHA/SmartCaptcha/hCaptcha, «я не робот»). `network_log()` — XHR/fetch: метод, URL,
   статус, типы, обрезанный образец тела (только в памяти). `export_session()` — cookies
   разрешённых хостов + bearer, если браузер сам слал `Authorization` на origin (перехват
   запроса) или он лежит в `sessionStorage` (Playwright `storageState` его не снимает — снимай
   скриптом). `browser/factory.py` → эта реализация.
3. **LoginFlow = SessionProvider** (`browser/login.py`, `ensure(ctx, user_id, connection_id)`):
   (а) сессия из Vault (`kind=session`) проверяется пробой `success.probe` пресета → годна —
   вернуть; (б) есть пароль в Vault → войти автоматически по шагам пресета; (в) иначе —
   интерактивно: для каждого шага формы `ctx.ask_secret(InputBlock(secret=True, …))` для пароля
   и кода, `ctx.ask(InputBlock(…))` для логина (`autocomplete=username`); push-подтверждение —
   `ctx.emit(WaitBlock)` и ожидание признака успеха до 2 мин; капча или незнакомая страница —
   `LoginBlock` (запасной экран) и ожидание. После успеха: сессия и (если вводились) логин и
   пароль → Vault; при первом входе на origin — **выучить пресет**: шаги, селекторы полей,
   признаки успеха/протухания (`login_presets`, без личных значений). Ошибки: неверный пароль —
   понятный текст и повтор шага (не больше 3 раз, затем пауза 10 мин); защита от ботов —
   `source_bot_protection`, автоповторов нет. `browser/factory.py: build_sessions` → LoginFlow.
4. **Запасной экран** (`browser/router.py`, `browser/screen.py`): `POST
   /connections/{id}/login-session` выдаёт одноразовый тикет (60 с) и `wsUrl`; WS проверяет тикет
   и `Origin` до апгрейда, один зритель; CDP screencast JPEG с адаптивным качеством и частотой по
   `ack`, ввод мышью/касанием/клавиатурой. Цели из ADR-0001: p95 ввод → кадр ≤ 150 мс локально,
   первый кадр ≤ 2 с, автопереподключение ≤ 3 с без потери контекста. Кадры и события ввода — ни
   в лог, ни на диск. Тест измеряет задержку на фикстуре и печатает её в отчёт.
5. **fakeuni**: расширь `tests/fakeuni/login.py` — вариант с push-ожиданием, страница с
   «капчей» (iframe-заглушка), SSO-редирект на второй хост `id.fakeuni.test`. Подними fakeuni по
   HTTPS локально (самоподписанный сертификат в фикстуре, `ignore_https_errors` в тестах,
   `--host-resolver-rules` для `*.fakeuni.test`).

## Готово, когда

Тесты с настоящим Chromium (маркер `browser`) проходят локально и в CI: вход с паролем и кодом
через зеркало формы (блоки `input`/`secret`, ответы через `InMemoryJobContext`), автовход по
паролю из Vault после протухания, push-ожидание, капча → `LoginBlock`, выученный пресет без
личных значений, проверка C1 (маркеры `P@ssw0rd-FIXTURE` и `424242` не встречаются в событиях,
логах, пресете и `secrets` кроме шифртекста), запрет чужого хоста через прокси.

## Не делаешь

Обучение рецепта данных и sync (W3), очередь и SSE (W1), интерфейс экрана (W4).
