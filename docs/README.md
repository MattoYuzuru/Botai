## Правила документации

- Источник правды по архитектуре и границам — `docs/v4/`. Если документ
  противоречит [решениям v4](v4/06-decisions.md), правится документ.
- Документ честно отмечает статус: `draft`, `proposed`, `accepted`,
  `implemented`, `validated`. Написанный документ не делает поведение сделанным.
- Фактическое утверждение о вузе, цене или инструменте сопровождается
  источником и отметкой уверенности: **Ф** — проверено, **П** — предположение.
- Устаревший документ правится, а не дублируется новым. Решения владельца —
  [06-decisions.md](v4/06-decisions.md), не ADR.
- Живые проверки фиксируются датой, SHA, сценарием, успехом/барьером и путём к
  артефактам; сырые сессии/скриншоты — только вне репозитория.
- Никаких секретов, cookie, персональных данных и секретных ссылок в документах:
  репозиторий публичный.
