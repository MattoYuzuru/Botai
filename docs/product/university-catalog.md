# Подсказки названий вузов

Решение владельца, 2026-10-28. `backend/src/botai/spaces/university-names.json` содержит
20 названий и распространённых сокращений. Подборка включает ведущие российские вузы
и дополнительные технические вузы Москвы; порядок подсказок не заявлен рейтингом.

Источники названий: [RAEX-100 за 2026 год](https://raex-rr.com/education/russian_universities/top-100_universities/2026/),
[сведения МИЭТ](https://old.miet.ru/sveden/common), [Центральный университет](https://cu.ru/).
Неформальные варианты — поисковые синонимы, не официальные названия.

`GET /universities` объединяет подсказки с выученным реестром. Поиск учитывает регистр,
пробелы, пунктуацию и е/ё. Существующая запись сохраняет ID, адреса, акцент и предупреждение;
подсказка записывается в БД только при выборе вуза. Поиск ничего не подключает.
Пустой запрос возвращает весь выученный реестр для подписей существующих пространств.

В справочнике нет адресов, селекторов, пресетов входа и рецептов. Их по-прежнему получает
агент с участием студента. Контракты REST и схема БД не меняются.

На экране подключения поиск нового вуза отделён от «Ваших подключений». Если выбран
уже добавленный вуз, форма направляет к существующим подключениям; отдельный
источник можно добавить явным действием «Добавить другой источник». Повторный вход
использует существующее подключение. Настройки и добавление источников находятся в «Учёбе».
