### Что добавил Botai в `varya.js`

Все правки помечены комментарием `BOTAI:`. Файл по-прежнему один, без зависимостей, глобальный объект `Varya`;
он не переписан под React и не разбит на модули.

| Что | Зачем |
|---|---|
| Ситуации `sync`, `think`, `overdue`, `offline`, `reauth`, `error`, `idle`, `perch`, `wave` | Состояния продукта из [mascot.md](mascot.md) §2. `lines` у них пусты: реплики берёт реестр Botai `mascot/lines.ts` из настоящих данных |
| Поле `hold` у ситуаций (`eyes`, `props`, `loop`) | «Держащий» вид живой Вари, пока ситуация не сменилась. Оригинальные ситуации получили `hold`, повторяющий их прежний покой, поэтому их поведение не изменилось |
| Петли `l-run` (бег на месте), `l-calm`, `l-tilt` и кадры ног `legsB`/`legsC` | «Бег на месте» для `sync`/`connect`, сдержанное дыхание, наклон головы при `think` |
| Режим `still` (`mount({ still })`, `setStill()`) | `motion: 'static'`: анимаций нет, показывается поза `pose` ситуации; смысл (знак, глаза, предметы) сохраняется |
| Сезонные образы `skin` (`new-year`, `mug`, `leaf`; `setSkin`, `Varya.svg({ skin })`) | Реестр [mascot.md](mascot.md) §7: колпак со звёздочкой, кружка, листок |
| Новые предметы `key` (нужен вход), `cloudx` (нет сети) | Позы `reauth` и `offline` |
| `mount().act(name)` и таблица `ACTS` (`peck`, `shake`, `look`, `wave`, `nod`, `hop`) | Действия сцены пустого чата и кивок насеста |
| `opts.random`, `opts.idleRange`, `opts.lookRange` | Детерминированный idle: Botai передаёт свой генератор, на насесте она моргает часто и поворачивает голову раз в 8–14 с |
| `react()` не падает на пустых `lines`, длительность реакции — `ms` | Реплики ситуаций Botai живут вне renderer |
| `Varya.svg({ legs })`, поле `pose.legs` | Статичная картинка бега |
| `tools/export.mjs` пишет и `varya-skin-<id>.svg` | Спрайты образов для `staticFallback` реестра [mascot.md](mascot.md) §7 |

Реплики оригинальных ситуаций `doodle_vibe` («Дедлайн через 2 часа», «Посещаемость 60%» и т. п.) остаются в файле
как часть снимка, но **не показываются**: в них придуманные числа, а Botai не выдумывает данные. Обёртка
`Mascot` не передаёт `onSay`, это проверяет тест.

### Как пересобрать спрайты

```bash
node packages/design/src/mascot/vendor/tools/export.mjs
```

Тест `vendor.test.ts` сверяет список ситуаций и образов renderer с типами TypeScript и наличием файлов в `sprites/`.

### Как обновить Варю из `doodle_vibe`

Автоматически не обновляется. Если в источнике появится нужное: `git diff` между снимком `d84008e` и новым коммитом в
`doodle_vibe/mascot/varya.js`, перенести нужное вручную в `varya.js` Botai, сохранив пометки `BOTAI:`, затем пересобрать
спрайты и обновить коммит в таблице выше.

### Правила проекта к вендоренному коду

- Biome и `design-lint` его не проверяют (`biome.json`, `EXEMPT` в `design-lint.mjs`): код чужой, цвета и `@keyframes`
  внутри него — часть renderer. Всё, что вокруг него (`mascot/*.ts`, `ui/mascot*`), проверяется как обычно.
- Renderer не ходит в сеть, не читает хранилища и не получает данные учебы: на вход идут только ситуация, тема, образ и
  размер ([mascot.md](mascot.md) §1, правило `mascot-data`).
