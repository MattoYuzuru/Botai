# Адаптивное исследование источника

Состояние на 28 октября 2026: реализован ограниченный цикл в существующем стеке; регрессии добавлены для CI. Живое подключение вуза подтверждает владелец. Это продолжение FR-005–FR-008, FR-016 и NFR-013, сохраняющее границу ADR-0005: модель пишет спецификацию, исполняемого кода от модели нет.

## Что изменилось

Раньше сборщик выбирал первые ссылки меню, обходил до шести страниц и передавал один снимок автору рецепта. Модель не могла выбрать следующий раздел, открыть наблюдаемую вкладку или запросить более подробную структуру ответа. Ссылка на курсы при неявном выборе данных могла приводить к поиску расписания.

Теперь `learn/discovery.py` удерживает один браузерный контекст на проход исследования. После каждого перехода обновляются DOM, доступные ссылки, проверенные вкладки чтения и изменения сетевых ответов. Отдельный вызов модели выбирает действие по ссылке на объект, который уже зарегистрирован исполнителем:

- `navigate(l…)` — переход по наблюдаемой безопасной ссылке того же origin;
- `inspect(p…/r…)` — более подробная обезличенная структура просмотренной страницы или ответа, без нового запроса;
- `activate(t…)` — открытие вкладки `role=tab`, для которой браузер проверил связанный `tabpanel` и отсутствие формы/опасного действия;
- `finish` — передача доказательств автору рецепта.

Модель не может передать новый URL, селектор, JavaScript или тело запроса. Ссылки проверяются повторно перед переходом; вкладки имеют серверные ссылки, связанные с текущим DOM. Повторное использование устаревшего состояния отклоняется. Обычные клики и ввод в браузере чтения остаются запрещены.

Для нового общего подключения действует режим `auto`: модель предлагает доступные виды из существующего словаря с опорой на просмотренные страницы и ответы. Явный выбор сохраняется в режиме `requested`; исключённые пользователем виды не добавляются. Явное уточнение после автоматического обнаружения заменяет автоматически выбранные виды. Старые контексты с сохранённым списком видов трактуются совместимо как явный выбор.

Автор рецепта работает отдельным шагом. Его результат по-прежнему проходит схему, lint, canary и подтверждение пользователя. Само предположение модели о наличии курсов или оценок не считается доказательством работоспособности рецепта.

## Ограничения и завершение

На один проход заданы максимум десять шагов модели, двенадцать представлений страницы, двести наблюдаемых запросов, девяносто секунд и 150 тысяч входных/выходных токенов. Общий бюджет задания сохраняется. Количество запросов проверяется между действиями; сетевые ограничения соединения дополнительно исполняет EgressProxy. Два действия без новых данных завершают цикл. В итоговый контекст выбираются полезные страницы и ответы, а не первые страницы меню.

Достижение ограничения показывается как неполная проверка: это не доказательство отсутствия данных. Неизвестный или некорректный план возвращает ограниченный детерминированный обход. Провайдер без возможности отдельного планирования также использует этот путь; тестовые очереди автора не расходуются на планировщик.

Если восстановленный браузер показывает страницу входа, автор рецепта не вызывается. Explorer один раз запрашивает принудительное восстановление входа через LoginFlow и исследует источник заново с новой сессией. Пароль, MFA и капча проходят существующие защищённые controls; повторный отказ получает код ошибки авторизации, а не `not_found`.

## Что это пока не обеспечивает

Произвольные JavaScript-кнопки, формы, неизвестные POST/GraphQL и автоматическое расширение списка разрешённых хостов недоступны. WebSearch в этот цикл не добавлен: публичный поиск не заменяет авторизованное чтение LMS. Новые типы доменных данных не создаются автоматически — используются существующий словарь и адаптеры.

Регрессии покрывают выбор десятой ссылки вместо первых шести страниц, дальнейший переход к данным курса, инспекцию нового сетевого ответа, автоматическое обнаружение курсов, явное ограничение расписанием, исключённые виды, отклонение выдуманных ссылок, остановку по бюджету и единственную попытку повторного входа. Локальные проверки не запускались по указанию владельца; результаты даёт CI.
