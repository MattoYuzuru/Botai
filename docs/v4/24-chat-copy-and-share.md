# Копирование сообщений и «Поделиться чатом»

Статус: **реализовано 2026-11-05** (ветка `feat/chat-copy-share`), в production — после деплоя.
Проверено: L1 (pytest API и миграции), L0/L1 фронтенда (Vitest), ручная проверка на стенде с моками.
Не проверено: живой production с двумя аккаунтами.

## Копирование

- У каждого сообщения человека и каждого текстового ответа агента в строке времени есть «Скопировать».
  Кнопка проявляется при наведении на сообщение или фокусе с клавиатуры; на касании видна всегда.
- Копируется исходный markdown сообщения (как в ChatGPT/Claude). После нажатия на 2 с — галочка и
  «Скопировано» (объявляется скринридеру); браузер не дал доступ к буферу — «Не скопировано».
- Пока сообщение уходит или печатается, кнопки нет. Общий помощник `copyText` живёт в `packages/design`
  (`lib/clipboard.ts`), им же пользуется `HandoffCard`.

## Поделиться чатом

- В верхней полосе сохранённого чата — «Поделиться». Шит: «Создать ссылку» (ссылка сразу копируется),
  «Скопировать ссылку», «Открыть», «Закрыть доступ».
- Ссылка `/shared/<id>`: `id` — случайный токен (`secrets.token_urlsafe(16)`), не ULID. Одна ссылка на
  чат (`chat_shares.thread_id` уникален); повторное «Поделиться» возвращает ту же ссылку, «Закрыть доступ»
  удаляет строку, и следующая ссылка будет новой. Удаление чата или пользователя удаляет ссылку (CASCADE).
- Открыть может **любой вошедший пользователь BotAI**; без входа — экран входа и возврат на ту же ссылку
  (`?next=` принимается только для путей `/shared/…`).
- Видно: заголовок, имя владельца, дата, тексты сообщений, цитаты, **названия** файлов. Не видно: шаги
  агента, задачи, вопросы, источники ответа, сами файлы, id вложений и адрес треда владельца.
  Чат «живой»: новые сообщения видны по той же ссылке.
- Внутренние ссылки ответа (`botai://threads/…`, вложения, документы) открываются в новой вкладке и
  работают только у того, у кого к ним уже есть доступ; у остальных — «не найдено».
- Владелец по своей ссылке видит «Открыть чат».

## API

| Метод | Путь | Что делает |
|---|---|---|
| `GET` | `/api/v1/chat/threads/{id}/share` | ссылка чата или `null` |
| `PUT` | `/api/v1/chat/threads/{id}/share` | открыть ссылку (идемпотентно) |
| `DELETE` | `/api/v1/chat/threads/{id}/share` | закрыть ссылку |
| `GET` | `/api/v1/shared/chats/{share_id}` | чат по ссылке для любого вошедшего |
