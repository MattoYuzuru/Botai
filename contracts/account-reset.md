# Сброс продуктовых данных аккаунта

Статус: accepted, 2026-10-29. FR-023, NFR-001, NFR-013.

Оператор может очистить продуктовые данные одного однозначно установленного владельца,
сохранив `users`, `auth_sessions`, приглашения и права. Очистка не является публичной
операцией API. Перед ней нужны защищённая резервная копия и остановка заданий владельца.

`GET /api/v1/me` может возвращать заголовок `X-Botai-Data-Reset` — время последнего
сброса в миллисекундах Unix. Значение получается из серверного события
`audit_log.kind=product_data_reset` только для аутентифицированного `user_id`.
Заголовок не содержит секретов; без сброса отсутствует. Ответ не кэшируется.

Клиент до отправки сохранённой очереди сверяет этот маркер с локальной отметкой
этого аккаунта. При новом маркере он удаляет только его старые сообщения очереди
(`createdAt <= resetAt`), привязки заданий и снимки BotAI, затем запоминает маркер.
Новые сообщения, созданные после сброса, сохраняются. Повторный ответ с тем же
маркером ничего не очищает. Аккаунт, cookie входа, настройки оформления, чужие
очереди и данные других origin не затрагиваются.

Совместимость: заголовок optional, JSON `MeOut` не меняется. Потребители: API auth,
операторская очистка, PWA API-клиент, очередь чата и offline snapshots. Старый клиент
может игнорировать маркер, поэтому для завершения очистки требуется перезагрузка
на актуальную версию PWA. Проверки включают изоляцию владельца, идемпотентность,
сбой хранилища и очистку во время ожидающей проверки сессии.
