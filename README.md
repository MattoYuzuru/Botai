# BotAI

Учебный хаб студента: расписание, дедлайны, оценки и домашки из нескольких
вузов в одном месте, с агентом, который отвечает на вопросы по этим данным.
Веб-приложение (PWA), ставится ярлыком на телефон, открывается из России без VPN.

**Статус на 27 октября 2026: реализация MVP.** Решения владельца — [QUESTIONS.md](QUESTIONS.md),
архитектура в картинках — [HLD](docs/architecture/hld.md) и [LLD](docs/architecture/lld.md).

## В чём идея

Существующие агрегаторы поддерживают вуз, только если кто-то вручную написал
под него парсер. Здесь вуз подключает **агент**:

1. Студент выбирает вуз и вводит логин, пароль и код в нативные поля BotAI —
   сервер переносит их на страницу входа вуза в своём браузере. Пароль хранится
   зашифрованным для автоматического повторного входа; капчу решает человек.
2. Агент ходит по разделам только на чтение, показывает поток размышления и
   задаёт уточняющие вопросы интерфейсом (чекбоксы, поля), а не текстом.
3. Итог — **рецепт**: декларативный JSON без личных значений (origin,
   GET-эндпоинты, разметка полей). Студент подтверждает собранное.
4. Дальше все студенты этого вуза синхронизируются по рецепту со своими
   сессиями — детерминированно, без участия модели.

Чего мы не делаем: не обходим капчу и защиту от ботов, не пишем код под
конкретный вуз, не выполняем write-действия без подтверждения человеком.
