# Botai

Учебный хаб студента: расписание, дедлайны, оценки и домашки из нескольких
вузов в одном месте, с агентом, который отвечает на вопросы по этим данным.
Веб-приложение (PWA), ставится ярлыком на телефон, открывается из России без VPN.

**Статус на 26 октября 2026: проектирование.** Кода нет. В репозитории —
требования, архитектура, контракты, модель безопасности, дизайн-система и план
работ. Следующий шаг — ответы на [вопросы к владельцу](QUESTIONS.md) и этап 0.

## В чём идея

Существующие агрегаторы поддерживают вуз, только если кто-то вручную написал
под него парсер. Здесь вуз подключает **агент**:

1. Студент выбирает вуз и входит **сам** — в серверном браузере, который
   транслируется ему на экран. Пароль и код MFA не сохраняются, капчу решает
   человек. Приложение хранит только зашифрованное состояние сессии.
2. Агент ходит по разделам только на чтение, показывает поток размышления и
   задаёт уточняющие вопросы интерфейсом (чекбоксы, поля), а не текстом.
3. Итог — **рецепт**: декларативный JSON без личных значений (origin,
   GET-эндпоинты, разметка полей). Студент подтверждает собранное.
4. Дальше все студенты этого вуза синхронизируются по рецепту со своими
   сессиями — детерминированно, без участия модели.

Чего мы не делаем: не обходим капчу и защиту от ботов, не храним пароли вуза,
не выполняем write-действия без подтверждения конкретного запроса человеком.

## Откуда что взято

Маскот и часть решений по входу переиспользуются из проекта владельца
`doodle_vibe`; дизайн-метод (OKLCH-токены, роли типографики, плотность,
design-lint) — из `BPMN.Space`. Внешние проекты `workflow-use` и `Integuru`
изучены как идеи; их код не заимствуется (AGPL-3.0).
