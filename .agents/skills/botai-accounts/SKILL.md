# Доступ к BotAI

Локальный операторский навык для агента в этом репозитории. Он запускается на
компьютере владельца; приложение и сервер не получают новый API или интерфейс.
Основание: D-001 в `docs/v4/06-decisions.md`. Текущая авторизация —
`backend/src/botai/auth/{service,router,schemas}.py`.

## Создать аккаунт

Просьба «создай аккаунт для Саши» уже разрешает создание. Возьми указанное имя
и почту; если почты нет, используй автоматически сгенерированный адрес
`botai-test-…@example.com`. Это только логин BotAI: почтовый ящик не создаётся,
подтверждение почты не требуется. Не спрашивай почту ради тестового аккаунта.
Если имя не указано, используй «Тестовый аккаунт».

Из корня репозитория:

```bash
python3 .agents/skills/botai-accounts/scripts/accounts.py create \
  --name 'Саша' --request-id friend-sasha-20261101
# С настоящей почтой: добавить --email friend@example.com
```

Выбери уникальный `--request-id` для новой просьбы и сохраняй его при повторе
после ошибки. Повтор того же запроса сверяет аккаунт с локальным секретом;
чужой или уже существующий пароль не сбрасывает. Новый тест с нуля — новый ID.
Профиль обычный (`is_owner=false`), без вузов, источников, чатов и памяти.
Вход — почта + отдельный пароль BotAI. Ключ модели общий, выдавать его человеку
не нужно. Общие рецепты вузов остаются общими; это чистый пользователь, а не
сброс всей базы знаний сервера.

## Пригласить на самостоятельную регистрацию

Если человек хочет сам выбрать имя, почту и пароль:

```bash
python3 .agents/skills/botai-accounts/scripts/accounts.py invite \
  --request-id invite-sasha-20261101
```

Ссылка `/register?invite=…` одноразовая, действует 7 дней. Это регистрация,
а не magic-link для входа. Аккаунт появится, когда друг закончит регистрацию.

## Проверка и выдача

```bash
python3 .agents/skills/botai-accounts/scripts/accounts.py list
```

По умолчанию цель — production BotAI: SSH `mnema`, контейнер `botai-api-1`,
`https://botai.mnema.app`. Флаги `--host`, `--container`, `--base-url`
используй только для указанного владельцем другого окружения. Перед SSH следуй
инфраструктурному навигатору из `/Users/yuzuru/AGENTS.md`, если он доступен.

Помощник печатает только результат, идентификатор, логин и путь к выдаче.
Пароль/ссылка сохраняются вне репозитория в
`~/.local/state/botai/accounts/<request-id>/access.json` (каталог 0700,
файл 0600). Не читай содержимое этого файла в вывод инструмента, промпт или
чат. Передай владельцу ссылку на локальный файл: он сам открывает его и
передаёт другу. Не отправляй сообщения другу без отдельной просьбы.

Если нужно войти в Chrome, подготовь страницу входа с логином. Пароль владелец
может скопировать из файла; применяй доступный защищённый ввод, если он есть.
Не вставляй пароль в аргументы вызовов или видимый вывод. Существующие сессии,
аккаунты и учебные данные сохраняй. Изменение пароля, отключение, удаление и
чистка данных не входят в этот навык.

Если SSH оборвался после отправки запроса, результат неизвестен: повтори только
с тем же `--request-id`. При конфликте имени/почты/пароля остановись и сообщи
об этом, не подменяй существующий аккаунт. Повтор не продлевает приглашение.
