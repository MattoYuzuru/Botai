- Адрес студента в пути. Подставляй `{имя}` из bootstrap только вместо сегмента, который в наблюдении показан меткой `<v…>`. Слово вроде `me`, `current`, `self` в наблюдённом пути или в значении query — не идентификатор, а литерал: сайт сам понимает его как текущего студента. Оставь такой путь ровно как его отправила страница, без bootstrap: адрес с чужим значением вернёт «не найдено».
- Ключ query, который в наблюдённом адресе повторяется (`?tag=a&tag=b&tag=c`), записывай списком всех значений в том же порядке: `"query": {"tag": ["a", "b", "c"]}`. Нельзя оставить одно значение или пропустить ключ: другой набор значений читает другие записи, а проверка сравнивает ключи с наблюдением вместе с их числом.
- Вложенные списки (группа → записи → вложенные объекты) читай секцией `collections` (до четырёх уровней: `{"as": "group", "path": "/groups"}`, `{"as": "entry", "path": "/items"}`), а поле внешнего уровня бери через `from`: `{"from": "group", "path": "/parent/title"}`. Один `itemsPath` вложенные массивы не проходит. Каждый уровень — именно массив: объект между массивами не уровень, а часть указателя (`/meta/people`). `required: true` ставь только полю, которое есть в каждой записи: одна запись без него (аудитория онлайн-занятия) отклонит весь ответ.
- Если запись описывает не одно занятие, а правило повторения (даты начала и конца периода, день недели, время начала и конца, интервал в неделях), разверни его секцией `expand` с `type: "weekly"`. Нельзя собирать `startsAt` из даты начала правила: получится одно занятие из прошлого. Поля секции: `startDate`, `untilDate`, `weekdays` (число 1–7 или слово источника: `monday`, `пн`…), `startTime`, `endTime` (или `durationMinutes`), `intervalWeeks` (число 1–4 или указатель на поле интервала в правиле), `timeZone`, `horizon` (`{"from": "{weekStart}", "days": 90}`). В `fields` при `expand` не пиши `startsAt` и `endsAt`. `externalId` — стабильный идентификатор правила (его собственный id, а не название курса: у лекции и семинара курса названия совпадают). Название курса, тип занятия (`kind`, `kindText`), аудиторию (`location`), корпус (`address` или `attributes`) бери из того же правила, преподавателей — `teacher` с `transform: "joinNames"` (берёт только имена, почту не трогает).
